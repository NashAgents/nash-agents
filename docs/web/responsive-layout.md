# Nash Web Control Plane: 响应式视口与跨设备适配规范 (Responsive Layout)

## 1. 响应式断点标准

| 视口类型 | 断点宽度 | 目标设备样本 | 布局形态 |
| :--- | :--- | :--- | :--- |
| **Desktop** | `>= 1024px` | 13-16 寸 MacBook, 24-27 寸桌面显示器 (1440x900 - 1920x1080) | 经典三栏工作台：左侧持久导航与会话、中央对话流、右侧上下文抽屉 |
| **Tablet** | `768px - 1023px` | iPad Pro / iPad Air (820x1180), Android 平板 | 自适应双栏工作台：左侧可折叠抽屉、中央主视口、右侧滑动浮层 |
| **Mobile** | `< 768px` | iPhone 13/14/15/16 (390x844), 小屏 Android (360x780) | 单栏垂直流：沉底导航栏、移动端阶段卡片、底部弹出式抽屉 (Bottom Sheet) |

---

## 2. 桌面端三栏工作台 (DesktopLayout)

- **左侧边栏 (260px)**：
  - Nash 品牌标识与全局运行状态。
  - 核心功能导航路由列表（工作台、任务、任务图、集群、项目、记忆、审批、产物、设置）。
  - 会话历史列表，支持快速新建、重命名与一键删除。
  - 当前登录用户头像与一键登出。
- **中央主视口 (Flex-1)**：
  - 顶部极简 HeaderBar：显示运行动词、实时耗时与 Token 指示器、亮暗模式切换、语言切换。
  - Transcript 对话主视图：垂直原生滚动，消息自适应折行。
  - 沉底输入控制中枢：集成简洁的对话输入卡片与 Steer 暂存队列条。
- **右侧上下文面板 (340px, 可一键收起)**：
  - 当前任务关联的 DAG 迷你概览与拓扑跃迁。
  - 节点状态雷达（Tencent / Mac / WSL2 在线指示灯）。
  - 待审批项提醒与快捷放行卡片。
  - 本轮任务交付产物一览。

---

## 3. 平板端双栏触控体验 (TabletLayout)

- 针对触控交互优化点击热区（最小高度 44px）。
- 侧边栏默认以图标形式收拢或抽屉形式呼出。
- Vue Flow DAG 支持双指缩放 (`pinch-to-zoom`) 与单指拖拽平移 (`pan-on-drag`)。

---

## 4. 移动端单栏与安全边距 (MobileLayout)

- **顶部极简状态栏**：固定高度 48px，保留品牌标识与快速抽屉开关。
- **单栏流式呈现**：移动端完全隐藏右侧常驻面板，将上下文收敛为顶部或底部的可折叠卡片。
- **移动端阶段卡片 (GraphStageList)**：
  - 在移动端 DAG 自动降级为垂直阶段流卡片，每张卡片展示阶段名、节点名、主机别名、当前状态。
  - 通过暗灰虚线连接阶段箭头，免去小屏幕难以操作复杂有向图画布的痛点。
- **底部沉底导航栏 (BottomNav, 56px)**：
  - 提供 5 个主要功能触控图标（工作台、任务、任务图、集群、更多）。
  - 支持 iOS Home Indicator 安全区自适应 (`safe-area-inset-bottom`)。
- **软键盘防布局塌陷**：
  - 输入框激活时不触发全屏重绘，利用 `viewport-fit=cover` 与动态高度防止视口跳跃。
